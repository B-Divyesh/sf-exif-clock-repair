Terms

Exif Clock Repair is a local planning tool. It reads a limited set of documented JPEG EXIF fields and produces suggested sidecars. It does not guarantee a capture time is historically correct.

Your responsibility

Keep backups. Review findings and spot-check proposed corrections before importing a sidecar into another metadata tool. Do not treat a file timestamp as proof of when a photograph was made.

No original mutation

This version does not edit original image files. It exports JSON ledgers and XMP sidecars so another workflow can apply, inspect, or discard a proposal.

Availability

The product is supplied as-is, without a warranty. It has no account or cloud-storage service.
