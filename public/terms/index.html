Terms

Exif Clock Repair is a local planning tool. It reads a limited set of documented JPEG EXIF fields and produces suggested sidecars. It does not guarantee that a capture time is historically correct.

Your responsibility

Keep backups, review the findings, and spot-check any proposed corrections before importing a sidecar into another application. Do not treat a file timestamp as proof of when a photograph was made. You are responsible for any changes performed in a separate metadata editor.

No original mutation

This version intentionally does not edit original image files. It exports portable JSON ledgers and bundled XMP sidecars so an external workflow can apply, inspect, or discard them.
